## 🧠 Program Overview

**Fortinet Certified Fundamentals in Cybersecurity** introduces the foundational concepts of cybersecurity and today’s evolving threat landscape. Through structured eLearning modules, the program helps learners understand how cybersecurity principles are applied to protect systems, networks, and data, while also exploring potential career paths in cybersecurity.

### 📘 Key Topics Covered by Module:

#### Introduction to the Threat Landscape 3.0
- Overview of modern cyber threats  
- Information security principles  
- Malware attacks and prevention  
- Network and endpoint security  
- Security operations fundamentals  

#### Technical Introduction to Cybersecurity 3.0
- Core cybersecurity technologies  
- Application security and cloud services  
- Data privacy and secure networking  
- Threat intelligence and social engineering  
- Technical foundations for cybersecurity roles
