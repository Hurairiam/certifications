## 🧠 Program Overview

**Fortinet Certified Fundamentals** provides a comprehensive introduction to **cybersecurity for entry-level professionals**. The program consists of a **core course** and an **elective course**, each culminating in its respective exam.

### 📘 Key Topics Covered:

#### 1️⃣ Core Course: Introduction to the Threat Landscape 3.0 (NSE 1 Exam, 3 hrs)
- Overview of cybersecurity and its significance  
- Common types of cyber threats and attack vectors  
- Basic network security concepts and endpoint protection  
- Security policies, risk management, and best practices  

#### 2️⃣ Elective Course: Technical Introduction to Cybersecurity (NSE 2 Exam, 7.5 hrs)
- Core cybersecurity principles: confidentiality, integrity, availability  
- Advanced network security fundamentals and protection strategies  
- Firewalls, VPNs, and endpoint security concepts  
- Threat detection, response, and incident management  
- Malware, cryptography, and secure SD-WAN essentials  
- Social engineering and data privacy awareness
